# CIPReB - Web v1

Versión inicial estática para publicar rápidamente en GitHub Pages.

- Estructura básica inspirada en la web de referencia.
- Menús y submenús.
- Carrusel.
- Página de contacto.
- Pie institucional.
- `content.json` separado del diseño para preparar el futuro administrador.
- Las imágenes actuales son provisionales; podrán reemplazarse posteriormente.

## Publicación
Subir todos los archivos a un repositorio de GitHub y activar GitHub Pages.
